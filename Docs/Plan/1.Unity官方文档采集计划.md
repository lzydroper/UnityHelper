# Unity 官方文档采集计划

## 一、目标

采集 Unity 官方 Manual 与 Scripting API 页面，形成不少于 3000 条官方文档记录，为 Dify 官方文档知识库提供基础数据。后续补采使用增量模式，避免覆盖已上传到 Dify 的首批 bundle。

## 二、采集范围

| 数据类别 | 入口 | 用途 |
| --- | --- | --- |
| Unity Manual | `https://docs.unity3d.com/Manual/index.html` | 概念解释、功能模块、工作流说明 |
| Unity Scripting API | `https://docs.unity3d.com/ScriptReference/index.html` | C# API 用法、参数、返回值、示例代码 |

## 三、执行步骤

1. 复制配置文件：

```powershell
Copy-Item Scripts\KnowledgeCrawler\config.example.json Scripts\KnowledgeCrawler\config.local.json
```

2. 确认 `config.local.json` 中的 `unity_docs.max_pages` 不低于 `3200`，并配置 `section_targets`，避免 Manual 页面挤占 ScriptReference 覆盖。
3. 运行采集脚本：

```powershell
python Scripts\KnowledgeCrawler\crawl_unity_docs.py --config Scripts\KnowledgeCrawler\config.local.json
```

增量补采时使用：

```powershell
python Scripts\KnowledgeCrawler\crawl_unity_docs.py --config Scripts\KnowledgeCrawler\config.local.json --incremental --max-new-pages 200
python clean_existing_unity_docs.py --config config.local.json
python prepare_dify_dataset.py --config config.local.json --dataset unity_docs
```

增量模式会跳过 `unity_docs.jsonl` 中已有 URL，新增记录会额外写入 `raw/unity_docs/unity_docs_incremental_YYMMDD*.jsonl`。Dify 上传时只使用新增的 `unity_official_docs_incremental_*.md`，不覆盖已经上传的 `unity_official_docs_bundle_001.md`。

4. 检查输出文件：
   - `Data/KnowledgeBase/raw/unity_docs/unity_docs.jsonl`
   - `Data/KnowledgeBase/raw/unity_docs/html/*.html`
5. 运行质量统计：

```powershell
python quality_report.py --root Data/KnowledgeBase
```

## 四、质量要求

| 检查项 | 标准 |
| --- | --- |
| 文档数量 | 不少于 3000 条 |
| API 覆盖 | ScriptReference 不少于 900 条 |
| 页面来源 | 仅保留 `docs.unity3d.com` |
| 内容长度 | 单条正文建议不少于 300 字符 |
| 元数据 | 每条记录包含 `source`、`section`、`url`、`title`、`content`；增量记录包含 `crawl_batch` |
| 原始留痕 | 保存 HTML 原始页面，便于后续核查 |

## 五、风险与处理

| 风险 | 处理方式 |
| --- | --- |
| 官网结构调整导致链接变少 | 增加 seed 页面，或将具体版本文档入口加入配置 |
| 网络请求失败 | 降低请求频率，重跑脚本；保留失败记录用于复查 |
| 页面噪声过多 | 调整 `crawl_unity_docs.py` 中的 `DROP_SELECTORS` |
| 文档重复 | 后续在预处理阶段按 URL 和内容 hash 去重 |

## 六、交付物

1. Unity 官方文档 JSONL 数据。
2. 原始 HTML 备份。
3. 数量统计截图或日志。
4. 可导入 Dify 的清洗后 Markdown 文档。
