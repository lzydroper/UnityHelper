# 数据清洗分块与 Dify 导入计划

## 一、目标

将 Unity 官方文档和社区问题数据转换为 Dify 可导入的 Markdown 文档，并为每个片段补充来源、标题、URL、类别等元数据。

## 二、本地预处理任务

| 步骤 | 说明 | 工具 |
| --- | --- | --- |
| 格式统一 | JSONL 转 Markdown | `prepare_dify_dataset.py` |
| 文本清洗 | 去除多余空白、导航、页脚、重复换行 | `common.py` |
| 元数据标注 | 标注来源、类别、URL、section、chunk_id | `prepare_dify_dataset.py` |
| 分块 | 默认 1800 字符，180 字符重叠 | `config.local.json` |
| 清单生成 | 生成 `manifest.jsonl` 与 `manifest.csv` | `prepare_dify_dataset.py` |

## 三、执行步骤

```powershell
python prepare_dify_dataset.py --config config.local.json
```

输出目录：

```text
Data/KnowledgeBase/processed/dify_import/
Data/KnowledgeBase/processed/dify_bundle/
Data/KnowledgeBase/processed/manifest.jsonl
Data/KnowledgeBase/processed/manifest.csv
```

如果已经生成 `raw/unity_docs/unity_docs_clean.jsonl`，脚本会优先输出到干净版目录：

```text
Data/KnowledgeBase/processed_clean/dify_import/
Data/KnowledgeBase/processed_clean/dify_bundle/
Data/KnowledgeBase/processed_clean/manifest.jsonl
Data/KnowledgeBase/processed_clean/manifest.csv
```

其中 `dify_import` 是本地分块留痕目录，不建议在 Dify 免费版里逐个上传。免费版每次只能上传 1 个文件时，优先使用 `dify_bundle` 中的合并文件：

```text
unity_official_docs_bundle_001.md
unity_issues_cases_bundle_001.md
```

## 四、Dify 导入任务

1. 登录 Dify 后台，进入知识库模块。
2. 创建 `Unity_Official_Docs`，导入官方文档类 Markdown。
3. 创建 `Unity_Issues_Cases`，导入 GitHub/StackOverflow 问题类 Markdown。
4. 创建 `Unity_Error_Cases`，导入团队人工整理的典型报错案例。
5. 检查导入后的文档数、分段数、索引状态。
6. 截图保存以下内容：
   - 知识库名称
   - 文档数量
   - 分段数量
   - 索引完成状态

免费版推荐上传方式：

| Dify 知识库 | 上传文件 |
| --- | --- |
| `Unity_Official_Docs` | `Data/KnowledgeBase/processed_clean/dify_bundle/unity_official_docs_bundle_001.md` |
| `Unity_Issues_Cases` | `Data/KnowledgeBase/processed_clean/dify_bundle/unity_issues_cases_bundle_001.md` |

## 五、Dify 参数建议

| 配置项 | 建议值 |
| --- | --- |
| 嵌入模型 | `text-embedding-3-small` 或 `bge-m3` |
| 检索方式 | 混合检索 |
| Top-K | 8 到 12 |
| 相似度阈值 | 0.35 到 0.45 |
| Rerank | 开启 |
| Rerank 候选数 | 15 |
| 最终参考片段 | 5 |

## 六、质量抽检

1. 从 `manifest.csv` 中随机抽取 5% 文档片段。
2. 检查是否存在导航栏、版权页脚、空白片段、乱码。
3. 检查代码块是否完整。
4. 检查标题和 URL 是否可追溯。
5. 抽检结果写入测试记录表。

## 七、交付物

1. Dify 导入 Markdown 文件夹。
2. `manifest.jsonl` 和 `manifest.csv`。
3. Dify 知识库导入截图。
4. 数据质量抽检记录。
